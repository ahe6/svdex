# Security reporting

Report suspected vulnerabilities privately to **austin@svdex.com**. Include the
affected route/version, reproduction steps and likely impact. Do not send live
credentials, financial documents, investor identities or database exports; use
redacted details or local reproductions. No response-time or bounty commitment
is made here.

Do not publish an exploitable issue or another member's private information in a
public GitHub issue. GitHub private vulnerability reporting may be used if it is
enabled for the repository; email is the documented fallback.

The supported runtime is the Discourse plugin/theme installation in this
repository. Production credentials, member records and historical archived
applications are not part of this public source distribution.

Maintainers should preserve source/version details, reproduce in isolation,
review related permission paths and coordinate a fix before public disclosure.
Credentials found in Git history require rotation and history/publication review;
removing the latest copy alone is insufficient.
